Project: HR document checks

Passage: Every flag is explained, a person decides

Context: Local, self-hosted prototype; README architecture section.

Verified notes: Uploaded PDFs and scans pass pre-flight checks, then Docling extraction with a RapidOCR fallback when confidence is low, schema and business validation, and cohort anomaly detection. Each flag carries a rule, severity, explanation and remediation, with sensitive values masked. The system never writes to an HR information system on its own.

Limitations:
- Prototype tested on synthetic sample documents only.
